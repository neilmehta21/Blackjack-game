# 🃏 Blackjack Game

A simple **Blackjack Game** built with Python as part of my **100 Days of Code: The Complete Python Pro Bootcamp by Angela Yu** journey.

This project helped me practice Python fundamentals by creating a playable Blackjack game where the user competes against the computer and tries to get as close to 21 as possible without going over.

## 🎮 How It Works

The player and computer are dealt cards from a standard deck.

The player can choose to:

* **Hit** — Draw another card
* **Stand** — Keep the current hand

The goal is to get a hand value as close to **21** as possible without exceeding it.

The computer follows its own rules and continues drawing cards until it reaches the required score.

### 🏆 Blackjack Rules

* Cards from **2–10** are worth their face value.
* **Jack, Queen, and King** are worth 10 points.
* **Ace** can be worth either 1 or 11, depending on the hand.
* A hand exceeding 21 is a **bust**.
* A score of 21 with the first two cards is a **Blackjack**.
* The player with the higher valid score wins.

## ✨ Features

* Player vs. computer gameplay
* Random card dealing
* Automatic score calculation
* Handles Ace as 1 or 11
* Detects Blackjack
* Detects busts
* Computer automatically plays its turn
* Determines the winner
* Option to play multiple rounds
* Simple command-line interface
